Kryptic Vision Hub

A Production-Grade, Rule-Based Cyber Security & Threat Analysis Toolkit.

Project Objectives

Kryptic Vision Hub was engineered to bridge the gap between theoretical cyber security education and practical defensive toolkit implementation. Unlike black-box machine learning engines, our architecture focuses on transparent, rule-based threat scoring that allows users and developers to understand exactly why a resource is classified as hazardous.

  • Implement deterministic phishing URL scoring using 12+ network & string rules.
  • Provide static code analyzers for SQL Injection and Cross-Site Scripting (XSS).
  • Simulate wireless security risks (Fake WiFi and Evil Twin attack vectors).
  • Deliver automated PDF report generation (ReportLab) and real-time Chart.js analytics.

Technology Stack

Backend Framework Python 3.10+ / Flask 3.0 (Modular Blueprints)
Database SQLite3 (Parameterized Queries & Foreign Keys)
Frontend Architecture HTML5, CSS3, Bootstrap 5.3, Vanilla ES6 JavaScript
Typography & Icons Google Font Inter, Bootstrap Icons 1.11
Reporting & Charts ReportLab 4.1 PDF Engine, Chart.js 4.x Visualizations
